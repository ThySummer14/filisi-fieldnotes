# 最喜欢的字体，未必读得最快

如果一项研究说，换字体能让人读快35%，最诱人的下一句当然是：换哪一种？但这个问题恰好绕过了研究的重点。最快的字体因人而异；更重要的是，实验里事后选出的“个人最快”，不等于明天安装它就能稳定得到同样幅度的提升。

Wallace等人在2022年发表的研究留下了这样一组结果：参与者使用各自测得最快的字体，平均阅读速度约为每分钟314词；最慢字体约232词，偏好字体约275词。前两者相差约35%，最快与偏好字体相差约14%。研究没有找到一款对所有人都获胜的字体，字体偏好也未能可靠预测阅读速度。[1]

## 先拆开那个35%

研究整体考察了16款字体，但每位参与者测试其中五款。最终分析保留352人的数据；实验还调整字号，使不同字体在知觉尺寸上更接近，而不是简单给所有字体填上同一个像素数。[1]

这些细节改变了结果的用途。它说明值得研究个人差异，却不能把某一字体的名字写进“效率提升35%”的统一处方。每个人的最快与最慢，都从有限测量里挑选出来。测量波动也会进入这个最大差值，这是对研究使用方式的统计提醒，并非论文已经证明全部差异来自噪声。

一个假想例子能说明风险：两款字体的真实速度都为每分钟250词。第一次短测，一款碰巧测得270，另一款230。事后选出前者，并不会让真实阅读能力凭空增长40词。现实里当然可能存在真正的字体效应，但要估计可重复收益，应当用未参与选优的新文章再次测试，而不是同时拿同一批数据挑赢家、宣布收益。

同样，短段落里的速度结果没有直接回答读完一小时后是否疲劳、隔天记住多少，以及读者愿不愿意继续。偏好与速度不是一个指标，也不意味着偏好可以被忽略。

## “都是12号”没有控制好字的大小

Legge与Bigelow的综述解释了一个容易被界面数字掩盖的问题：字号描述字体的名义尺寸，不是读者实际看到的小写字母高度。不同字体的小写x高度占字号的比例不同，同样的12点，字身可以显得明显不同。[2]

因此，两款字体的速度差异，可能混合了字形、实际尺寸、字距等变化。“衬线是否帮助阅读”的争论也受这种混合影响。拿两款成品字体直接比较，即使读出了差异，也不能把功劳或责任全部归给字母末端的细小衬线。

Arditi与Cho在2005年专门制作字体，改变衬线大小，并操纵间距，尽量把因素拆开。连续阅读和快速逐项呈现任务中，他们没有发现稳定的衬线阅读速度优势。但阅读实验样本很小，涉及的字体与任务也有限；这个结果支持谨慎对待“衬线天生更快”，不支持断言所有衬线体与无衬线体都同样易读。[3]

这类受控实验看起来不如字体排行榜直接，却更接近真正的设计问题：改变的究竟是什么？若增加衬线同时缩小内部空间、改变字符宽度，最后得到的是一套共同变化的设计，不能只用一个分类词解释。

## 习惯也有好几种

有人把字体表现完全归结为熟悉：常见的就好读，陌生的就费力。Beier与Larson在2013年区分了“字体以前见过”与“字母骨架常见”，把新旧字体和常见、不常见字形组合起来研究。[4]

参与者经历约20分钟的阅读后，总体阅读表现改善，但不同熟悉条件之间未检出可靠的阅读速度主效应。主观评价却更苛刻地对待不常见字形。结果提示，在研究所用、事先考虑可辨识性的字体中，觉得别扭和实际读慢可以分离。[4]

这里仍不能推到“随便多难的字体，适应20分钟都会一样快”。熟悉字体也在后测中改善，练习、短期调适等解释仍需区分；实验选用的可读字形，更不能代表所有装饰字体。读者不喜欢某种字形，也可能真的因此少读，尽管规定时间内的实验速度未下降。

## 为自己的阅读选字，怎样少被骗一次

从这些证据推出来的务实做法，是先把目标说清楚。如果读的是小说，舒适和愿意长读可能比几分钟里的最高速度重要；如果要找错字，漏检率不能被平均速度掩盖。

比较时，至少让实际字形尺寸、行宽、对比度尽量接近，准备难度相当而不重复的材料，交换测试顺序，同时记录理解和不适。初选后隔一段时间再测，看看优势是否还在。这样的个人小实验无法自动获得专业研究的精度，却比只看一张字体样张更接近实际任务。

本文涉及的主要实验使用拉丁字母文本。汉字的结构密度、字面率和阅读单位不同，不能把英文每分钟词数的差值原样搬成中文收益。字体设计里值得保留的结论反而很朴素：观看的喜欢、辨认的准确、连续阅读的速度，都需要分别观察。一个按钮上的字体名称，代替不了这些测量。
