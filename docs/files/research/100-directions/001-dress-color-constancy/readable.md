# 同一条裙子，两套照明

2015年那张蓝黑或白金的裙子照片，最值得保留的细节其实是：有人看见蓝棕。Lafer-Sousa等人的调查没有强迫参与者在网络上流传的两个答案中选择，而是让1401人自行填颜色。其中57%回答蓝黑，30%回答白金，11%回答蓝棕。研究者又让人从色域中匹配所见颜色，差异仍然存在。争论不能全部归给语言，更不能归给谁在故意唱反调。[1]

不过，这些比例属于当时那份样本。它不是一张全球人类色觉分布图。

## 屏幕给的是光，问题问的是布料

拍摄一块布时，相机收到的光已经混合了两类信息：照明的光谱，以及布料对各波长的反射。照片还经过相机处理，再由另一块屏幕发光。屏幕上的RGB数值可以精确读取，“这条裙子在普通照明下是什么颜色”却需要推断。

可以用一个刻意简化的算例说明其中的困难。假设某个波段收到的光强是0.3，照明强度与表面反射率分别是0.6和0.5，就能得到这个数；换成0.3和1，也能得到同一个数。这里忽略了几何、相机响应和跨波长计算，只展示一件事：单凭收到的光，无法唯一拆出照明和表面。真实视觉用周围物体、阴影、材质与经验限制可能答案。[2]

日常色恒常的作用，是让一件衣服经过窗边、灯下和阴影时仍大致保有颜色身份。裙子照片恰好让这项工作难做：画面里的照明关系含混，部分色彩变化又与自然光从偏蓝到偏黄的变化方向接近。将蓝色主要归给照明，视觉系统便会在估计布料时抵消较多蓝色；归给布料的份额多一些，蓝色就留下来了。这是有实验支撑的解释框架，却不能据此认定每个观察者脑中都执行同一条明确的“减蓝色”指令。[2][3]

## 改背景还不够，得让解释与对比唱反调

把裙子剪下来放到偏蓝或偏黄的背景里，颜色会变。这种演示很直观，但证据比它看起来弱：附近颜色本来就会改变一块颜色的外观，因此还不能确定人们真的改变了对照明的理解。

Witzel、Racey和O’Regan做了更有针对性的安排。他们给裙子配置能暗示日照或阴影的场景，同时让局部颜色对比的预测与场景照明的预测相反。观察结果支持场景解释的作用。他们还先给参与者看消除歧义的版本，再展示原图，发现先前的解释会影响随后看见的颜色。[2]

这一步比“背景变了，颜色也变了”更有辨别力。实验不是只增加一个现象，而是在两个可能机制之间制造分歧，再看知觉跟哪一个走。它支持照明假设参与颜色判断；至于这种假设来自终身经验、刚看过的一张图，还是眼前场景的组织，仍需要分开研究。

另一个反例来自反色。Winkler等人把原图的色彩方向反转，原本引发白蓝争论的浅条纹变成偏黄。87名大学生在原图上几乎均分为白色和蓝色回答，在反色图上却有94%报告黄色或金色，无人报告白色。[3]

这说明歧义并不对所有色相一视同仁。他们的实验还发现，人们把偏蓝色调归为白或灰的范围，比偏黄方向宽。把蓝色解释成照明可能与这种不对称有关。这里的“可能”应当留下：观察到蓝黄不对称，并不等于已经证明它由哪段生活经验造成。

## 早鸟与夜猫子的漂亮故事

一种流行说法很容易记住：早起者熟悉蓝色日光，所以看见白金；夜猫子熟悉暖色灯光，所以看见蓝黑。它把复杂知觉变成了性格小测验。

Wallisch在约1.3万人的在线调查中，确实发现照明判断与裙子颜色报告有关，并报告了符合昼夜类型解释方向的结果。但这仍是调查数据，照明判断和颜色报告可能互相影响；昼夜类型也不是对一个人多年所受光谱的直接测量。[4]

更麻烦的是，结果没有整齐复制。2015年研究的补充材料里，作息与白金回答只有轻微、未达显著的趋势。Lafer-Sousa与Conway在2017年进一步研究时，又发现睡眠与清醒时间的预测力比Wallisch结果暗示的弱。两项研究的招募方式、问的是初见时的记忆还是当前知觉、如何测作息，以及样本数量都不同。[1][5]

因此，更稳妥的说法是：照明估计有多种独立证据支持；用作息解释个体差异，证据混合且方法敏感。不能看到一个人的答案，就倒推出他的睡眠习惯、人格或视觉优劣。

## 一张商品图应该多给什么

从这些研究推到摄影和设计，一个实用判断是：颜色需要场景帮助解释。若目标是让别人判断衣物颜色，仅交付一块看似准确的RGB，仍可能保留照明歧义。保留合理的阴影关系、提供参照物、展示不同照明下的照片，值得优先于增加一句“实物更接近图片”。这是从机制出发的设计推论，不是上述论文已测出的转化率或退货率效果。

也不必从裙子争论跳到“所有现实都是主观的”。布料反射光的物理性质、照片的数值和人报告的颜色，是能够分别测量的对象。困难发生在它们之间的推断。那条裙子的真正启发，是提醒我们问清楚：此刻要比较的是屏幕发出的光，还是一个人据此估计的物体？
